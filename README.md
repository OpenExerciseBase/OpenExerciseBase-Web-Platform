# OpenExerciseBase-Web-Platform

The website of [OpenExerciseBase](https://openexercisedatabase.at), an open, evolving infrastructure for structured exercise knowledge. It is used to browse, contribute, and review exercises. The exercise data itself is in the [OpenExerciseBase-Database](https://github.com/OpenExerciseBase/OpenExerciseBase-Database) repository.
